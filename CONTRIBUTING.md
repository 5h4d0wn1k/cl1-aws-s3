## Contributing

Contributions are welcome. Please open an issue first to discuss changes.

### Guidelines

- Keep tools educational and clearly labeled for authorized security testing only
- Follow existing code style and project conventions
- Include tests for new functionality
- Never commit real credentials, API keys, or personally identifiable information
- Ensure all code compiles/lints cleanly before submitting
